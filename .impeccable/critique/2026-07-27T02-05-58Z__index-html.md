#### Priority Issues

- **[P2] Arbitrary Micro-Text Font Sizes**: 26 instances of hardcoded arbitrary font sizes (`text-[9px]`, `text-[10px]`, `text-[11px]`) across components (`AiAdvisor`, `Assessment`, `Contact`, `Footer`, `GlossaryTooltip`, `Header`, `Hero`, `Services`).
  - *Why it matters*: Bypasses the central type ramp in `DESIGN.md` and can decrease legibility on low-DPI displays.
  - *Fix*: Standardize micro-badge and tag sizes to explicit `text-xs` (12px) or introduce a named design token class (e.g. `text-badge`).
  - *Suggested command*: `$impeccable typeset`
- **[P2] Assessment Rapid Auto-Advance**: Option selection auto-advances slides after 280ms (`Assessment.tsx#L94-L96`).
  - *Why it matters*: Users who misclick using touch or keyboard might auto-advance to the next question before realizing their selection.
  - *Fix*: Add a brief visual selection highlight or a subtle undo toast before switching slides.
  - *Suggested command*: `$impeccable polish`
- **[P3] Hidden Mobile Kbd Indicator**: The `kbd` shortcut badge for `Ctrl+/` is hidden below the `sm` breakpoint in `Header.tsx#L149`.
  - *Why it matters*: Mobile/tablet users with external keyboards miss the power-user shortcut cue.
  - *Fix*: Render a compact visual badge or tooltip cue on small viewports.
  - *Suggested command*: `$impeccable adapt`
