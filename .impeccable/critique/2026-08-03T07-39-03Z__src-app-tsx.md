#### Priority Issues

- **[P0] Uncaught ReferenceError in GlossaryTooltip Mobile Click**
  - **Why it matters:** In `src/components/GlossaryTooltip.tsx:79`, `onClick={handleToggle}` references an undefined identifier `handleToggle`, causing an immediate React runtime crash when a user taps a GRC glossary term on mobile/touch screens.
  - **Fix:** Replace `onClick={handleToggle}` with `onClick={() => setIsOpen((prev) => !prev)}`.
  - **Suggested command:** `$impeccable harden src/components/GlossaryTooltip.tsx`

- **[P1] Missing Corporate Branding & Metadata on `@media print` Board Scorecard**
  - **Why it matters:** When a BUMN Executive or Audit Committee Chair prints the generated AI Executive Report for board meetings, `@media print` suppresses `#main-header`. The resulting physical paper lacks the company logo, date stamp, and explicit confidentiality classification.
  - **Fix:** Add a dedicated print-only header block (`hidden print:block`) at the top of the results step containing official branding, timestamp, and a "RAHASIA / CONFIDENTIAL" watermark header.
  - **Suggested command:** `$impeccable adapt src/components/Assessment.tsx`

- **[P2] Visual Keyboard Shortcut Hints on Assessment Option Buttons**
  - **Why it matters:** While `1`–`4` numeric key bindings are active in the assessment listener, power users and auditors do not see visual badge cues indicating that keys `[1]`, `[2]`, `[3]`, `[4]` can select answers directly.
  - **Fix:** Add subtle JetBrains Mono key badges `[1]`–`[4]` inside the option score circles in `Assessment.tsx`.
  - **Suggested command:** `$impeccable delight src/components/Assessment.tsx`

- **[P2] Personal Email Soft-Warning Does Not Require Domain Confirmation**
  - **Why it matters:** In `Contact.tsx`, entering `@gmail.com` or `@yahoo.com` shows a soft warning badge but still allows form submission. BUMN and banking client acquisition requires corporate or government domain validation.
  - **Fix:** Require explicit checkbox acknowledgment or highlight corporate email recommendation before enabling submission.
  - **Suggested command:** `$impeccable clarify src/components/Contact.tsx`
